## 🌟 Featured Projects

### 🎟️ Technorollix

**Next.js · TypeScript · React · Node.js · MongoDB · AWS**

A centralized event management platform built to replace fragmented Google Forms workflows with a single system for registration, payments, accommodation, participant management, and event information.

**Highlights**

* Supported **42+ events** through one centralized platform
* Designed server-side pagination for large participant datasets
* Implemented streaming Excel exports without loading entire datasets into memory
* Supported around **2,500 registered users over a month**
* Built reusable **role-based authorization** for students, event managers, and administrators

**React · Express · Socket.io · MongoDB · JWT · Razorpay · Tailwind CSS**

**Highlights**
